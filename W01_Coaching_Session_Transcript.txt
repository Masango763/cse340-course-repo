1. EXPRESS ROUTING IN SERVER.JS
Discussion:
Implemented modular routing using express.Router(), defined endpoint handlers (getHome, getCategories), and mounted middleware with app.use('/', staticRouter). Express matches incoming HTTP request URIs against registered routes to execute corresponding controller logic.

Code Snippet:
import { Router } from 'express';
const router = Router();

const getCategories = (req, res) => {
  const projectCategories = ['Environmental', 'Educational', 'Community Service'];
  res.render('categories', { title: 'Categories | CSE 340', categories: projectCategories });
};

router.get('/categories', getCategories);
export default router;

3. EJS PARTIALS AND PAGES
Discussion:
Configured dynamic views (index.ejs, categories.ejs), page layouts using express-ejs-layouts, partial components (header, footer), and EJS output tags (<%= %> vs <% %>). This decouples view templates from backend handler routes.

Code Snippet:
<section class="page-section">
  <h1><%= title %></h1>
  <ul class="category-list">
    <% categories.forEach((category) => { %>
      <li class="category-item"><%= category %></li>
    <% }) %>
  </ul>
</section>
